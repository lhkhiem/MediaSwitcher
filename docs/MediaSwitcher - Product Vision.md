# MediaSwitcher - Product Vision

## Project

MediaSwitcher

## Product Type

Windows Portable Application

## Mission

MediaSwitcher là phần mềm chuyển nguồn video chuyên dụng cho màn hình LED và máy chiếu.

Ứng dụng tập trung vào:

- Preview nhanh
- Thumbnail realtime
- Chuyển nguồn ổn định
- Giao diện cực kỳ đơn giản

Không hướng tới Broadcast Software như vMix.

Không hướng tới Live Streaming.

Không hướng tới Recording.

## Target Users

- Event Company
- Wedding
- Church
- Hotel
- School
- Conference
- LED Rental Company

## Core Features

- File Input
